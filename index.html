Capabilities

Every shortcut in the dashboard maps directly to common wireless ADB and scrcpy workflows.

12

Android 11+ Wireless Pairing

Guided pairing with a 6-digit code and pairing port, followed immediately by connecting to the main wireless debugging port.

34

USB-to-Wi-Fi Setup

Reads your USB phone's wlan0 IP automatically, enables adb tcpip 5555, verifies connectivity, and starts mirroring.

56

Normal & Low-Lag Mirroring

Launch standard mirroring or a tuned low-latency preset (--video-bit-rate=4M --max-size=1024) for weaker Wi-Fi.

789

Audio-Only Streaming

Forward Android 11+ audio without video using Normal, 64K Opus (200ms buffer), or 32K Opus (300ms buffer) presets.

H1H4H

Persistent IP History

Saves up to 10 successful IP:PORT endpoints locally across restarts and exposes top 4 slots for one-key reconnects.

PTC

Auto-Detect & Stream Control

Finds scrcpy.exe and adb.exe automatically, tracks active streams to stop them cleanly, or opens CMD in the scrcpy folder.

Quick Start

No installer or admin privileges required.

01

Extract scrcpy

Download the latest Windows release from Genymobile/scrcpy and extract it anywhere on your PC.

02

Download the launcher

Grab the latest .bat file from the Downloads section above and double-click to run it.

03

Pair and connect

Enable Wireless debugging on Android 11+, press 1 to pair, or connect via USB and press 3.

Note: Because the file is an unsigned plain-text .bat script, Windows SmartScreen may prompt on first launch (choose More info → Run anyway).
